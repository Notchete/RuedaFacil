## RuedaFacil
Aplicacion para gestionar sistema de alquiler de Vehículos
Capacidad para administrar clientes, empleados, vehículos, categorías de vehiculos y alquileres, con cálculo de precios de alquileres.

# Requisitos funcionales:
Gestión de clientes
Gestión de empleados
Gestión de vehículos
Gestión de categorías de vehículos
Gestión de alquileres
Cálculo de precios de alquileres
Consultas de información

# ¿Qué se ha usado?:
Java
MySQL
JDBC

# Estructura del Proyecto:
App.java: Principal
ConexionBD.java: Conexión a base de datos
DAO/: Clases de métodos
DTO/: Clases de datos
